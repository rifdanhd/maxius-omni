# Pemeriksaan lokal Maxius — 18 Oktober 2026

Status: pengujian browser akhir belum selesai. Belum dinyatakan 100% siap produksi.

## Perbaikan aplikasi

- Pengaturan toko membedakan token yang masih dapat dicoba diperbarui dari koneksi yang membutuhkan otorisasi ulang.
- Sinkronisasi tetap dapat dijalankan ketika access token habis dan refresh token tersedia. Toko dibekukan tetap terkunci.
- Lonceng tidak lagi melaporkan token yang dapat diperbarui sebagai koneksi putus.
- Sinkronisasi listing TikTok menggunakan layanan refresh dan kredensial aplikasi akun yang bersangkutan.
- Layanan token TikTok dan Shopee membaca token terbaru dari database agar pemanggilan berikutnya tidak memakai snapshot token lama.
- Promosi yang dikonfirmasi marketplace disimpan ke monitoring lokal. ID hasil verifikasi harus cocok; hasil tidak pasti tetap UNVERIFIED.
- Modal marketplace menggunakan dialog dengan fokus keyboard, Escape, dan nama yang dapat dibaca pembaca layar.

## Verifikasi

- `AUTO_SYNC_DISABLED=true SYNC_RETRY_DISABLED=true npm run build`: build setelah seluruh perbaikan aplikasi lolos, termasuk pemeriksaan TypeScript dan 111 route.

Hasil mesin tersedia di `.next-e2e/qa/`. Database pengujian memakai nama `maxius_test_*` pada PostgreSQL lokal.
